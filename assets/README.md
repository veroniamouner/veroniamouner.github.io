# Veronia Mouner — Portfolio

Personal portfolio website: graphic design, branding and web design.
Plain HTML, CSS and JavaScript, hosted for free on GitHub Pages. Bilingual (English / Arabic).

## Files

```
index.html          page structure
style.css           design
script.js           content (work, brands, websites), translations, gallery
assets/work/        portfolio images
assets/web/         optional website screenshots (egystone.jpg, catalog-now.jpg, onyxdecore.jpg)
assets/cv/          CV (PDF)
```

## Editing content

- **Add a design:** put the image in `assets/work/` and add it to the `WORK` list in `script.js`.
- **Add a brand identity:** add an entry to `CASES` in `script.js`.
- **Add a website:** add an entry to `SITES` in `script.js`.
- **Website screenshots:** by default the site cards show a live preview of each site.
  For a cleaner look, take a screenshot (16:10, e.g. 1440×900) and save it in `assets/web/`
  with the site's slug as the name, e.g. `assets/web/egystone.jpg`.
- **Arabic text:** the `AR` object in `script.js`.
